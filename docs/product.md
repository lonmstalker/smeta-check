# Продукт

Живой документ. Заполняется при старте конкретного проекта из шаблона;
человек со стороны читает его первым.

## Что за продукт

_Одним абзацем: какую проблему решаем, для кого, чем отличаемся._
(Шаблон: здесь пусто, заполнить при старте проекта.)

## Кто пользователи

_Роли и их цели. Сейчас в системе две роли:_

- **user** — обычный пользователь, работает со своими данными;
- **admin** — управляет пользователями и контентом.

## Бизнес-модель

_Как зарабатываем: подписка / разовые платежи / комиссия. Цены, тарифы._
(Заполнить при старте проекта.)

## Метрики успеха

_3–5 чисел, по которым понимаем, что продукт живёт: регистрации,
активные пользователи, конверсия в оплату, удержание._

## Ограничения

- Один дешёвый VPS на старте — бэкенд обязан оставаться лёгким.
- Команда маленькая — простота важнее универсальности.

## Устройства

Мобильная поддержка обязательна (решение июля 2026): интерфейс должен
быть пригоден на телефоне, планшете и десктопе. Раскладка ключевых
страниц проверяется скриншот-тестами на трёх ширинах экрана.
