# UC-004 — Сравнение смет нескольких бригад

Статус: запланировано, не реализовано. Строится поверх UC-003.

## Зачем (бизнес-ценность)

Когда смет две-три, вопрос не «где переплата», а «какая бригада
честнее». Ключевой инсайт продукта: самая дешёвая смета почти всегда
самая неполная — с учётом будущих допов порядок бригад может
перевернуться. Это самый убедительный кейс для сарафана: «смета на
850 тысяч оказалась дороже сметы на 1,1 млн».

## Актёры

- Пользователь с 2–3 сметами разных бригад.
- Система — приведение смет к каноническим позициям и сравнение.

## Сценарии

### UC-004.1 Сравнение side-by-side
1. Пользователь загружает 2–3 сметы (каждая проходит парсинг UC-003).
2. Система строит таблицу по каноническим позициям: где каждая бригада
   дороже/дешевле рынка, у кого состав работ полнее.

### UC-004.2 Прогноз реальной цены
1. Для каждой бригады система считает «прогноз реальной цены»:
   заявленная сумма плюс рыночная стоимость пропущенных обязательных
   работ (будущие допы).
2. Итог — рейтинг бригад по прогнозу, а не по заявленной сумме.

### UC-004.3 Покупка пакетом
Пакет «Выбор бригады» покрывает до 3 смет одной оплатой; либо
доплата за каждую смету сверх первой (цены — `docs/product.md`).

## Не входит (осознанно)

- Больше 3 смет в пакете — реальный кейс «выбираю из двух-трёх».
- Автоматический вывод «выбирайте бригаду N» — показываем цифры,
  решение остаётся за человеком.

## Критерии приёмки

- Две сметы с разным составом работ сводятся в одну таблицу по
  каноническим позициям; позиции, которых нет у бригады, видны явно.
- Прогноз реальной цены пересортировывает бригады в тестовом наборе,
  где дешёвая смета — самая неполная.
- Оплата пакетом открывает разбор всех загруженных смет сразу.
