# Новая фича: чек-лист

Сначала use case (скилл `workflow`). Затем по слоям, в этом порядке.

## Бэкенд

1. **Миграция** `server/migrations/000N_имя.sql`. Только вперёд, старые
   файлы не редактируются. Ограничения данных — в БД (NOT NULL, CHECK,
   UNIQUE, FK), а не только в коде.
2. **Домен** — папка `server/src/<домен>/` (образец: `items/`, сложный —
   `auth/`): `mod.rs` с транспорто-независимыми функциями. Правила:
   - чужие таблицы не трогать — только функции чужого домена;
   - ошибки — `ApiError` с ключом локализации; ключ добавить в ОБА файла
     `server/locales/{ru,en}/main.ftl` (тест сверки не даст забыть);
   - доменные метрики: `metrics::counter!("<домен>_<событие>_total")`.
3. **HTTP** — `<домен>/http.rs`: тонкие хендлеры с `#[utoipa::path]`,
   маршруты в `router()`, подключить в `lib.rs` (`merge` + `paths(...)`).
   Защита: параметр `user: CurrentUser` (вход) или `_admin: AdminUser`.
4. **Тесты** — в `server/tests/api/<домен>.rs` через `spawn_app()`
   (скилл `writing-tests`). Позитив + границы доступа + валидация.
5. **Контракт** — `make gen-api` (обновит openapi.json и типы фронта).

## Фронтенд

6. **Данные** — только TanStack Query (`useQuery`/`useMutation` +
   invalidate), типы — из `@/api/client` (никаких ручных интерфейсов API).
7. **Страница/компонент** — стиль и состояния по скиллу `ux`; общие куски
   выноси в `components/`, а не копируй.
8. **Тексты** — ключи в `web/src/locales/{ru,en}.json`, количественные
   формы: `_one/_few/_many` для ru, `_one/_other` для en.
9. **Тесты** — юнит через `renderApp`/`mockApi`; заметный пользовательский
   путь — сценарий в `web/e2e/` через фикстуру `user`.

## Финал

`make verify`; когда фича полностью готова и verify зелёный —
`make mutants` (мутационные тесты диффа: находят тесты, которые ничего
не проверяют; в цикле разработки не гонять — долгий); запись в
`docs/journal.md`; при изменении архитектуры — `docs/architecture.md`.
